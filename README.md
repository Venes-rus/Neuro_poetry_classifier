# Neuro_poetry_classifier
Дипломный проект бакалаврской работы в вузе. Нейросеть определяет автора стиха на основе последовательности LSTM, механизма внимания а так же ручных признаков и выводит основную характеристику. (Нейросеть на python)
Архив со стихами разбитый по авторам. Для обучения нужно запустить поочереди generate_csv.py, preprocess.py, train_model.py. После использовать графичиский интерфейс для работы с классификатором gui_app.py.
